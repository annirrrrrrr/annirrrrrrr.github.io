# Annie Zhu

Static React website for GitHub Pages.

Run `npm ci`, then `npm run dev` for editing or `npm run build` to build.
The build creates all five page directories so direct links and refresh work without a server.
GitHub Actions publishes the build when changes are pushed to main.

Content: lib/portfolio-content.ts
Page layout: components/portfolio.tsx
Styles: src/styles.css
Photos and resume: public/

Intended hosting: annirrrrrrr.github.io. No custom domain is configured yet.
